# Фаза 2 — Дизайн

Орієнтири від власника: відео головного екрана (повноекранне фото, велике слово, лічильник, скрол у чорне з чотирма фото-літерами), макет «Amazing corners of the planet» (стрічка наступних слайдів із номерами), макет «Journal X» (великі заокруглення, пігулки, фотокартки, чорний блок підписки).

## Головна, згори вниз
1. **Обкладинка** (`HeroShowcase`): карусель напрямків, паралакс і затемнення під час прокручування. Показ можна зупинити.
2. **«КОЛИ»** (`SeasonStrip`): чотири пори року, у кожній найкращий за погодою напрямок. Картки піднімаються з темряви разом із прокручуванням; клік обирає місяць на карті.
3. **«Куди поїхати?»** (`map/MapExplorer`): пошук на карті, регіони, клік по країні, точки напрямків, місяці, список.
4. **Підписка** — чорний заокруглений блок.

## Правила
- Темні: обкладинки, пори року, карта, підписка. Світлі (темні в темній темі): сторінки з текстом.
- Один шрифт (Manrope), чорно-білі кнопки; кольори лише для вердиктів сезону.
- Вибір на карті живе в адресі: `?region=europe&country=spain&month=7`.
- `prefers-reduced-motion`: без автопоказу, паралаксу й польотів карти.

## Фото й карта
- Фото: Wikimedia Commons, список у `src/data/photo-sources.json`; `npm run fetch:photos` стискає їх у `public/photos` і записує авторів. Приймаються лише CC0, Public domain, CC BY, CC BY-SA. Автори показані біля великих фото й на `/credits`.
- Карта: Natural Earth (`world-atlas`), `npm run build:map` → `public/map/world.json` (≈140 КБ gzip). Проєкція в `src/lib/map-projection.ts`.
- **Крим:** вихідні дані малюють його у складі Росії; `src/lib/map-corrections.ts` повертає його Україні під час побудови карти. Тест `map-corrections.test.ts` перевіряє і виправлення, і готовий файл. Після оновлення `world-atlas` обовʼязково запускати `npm test`.
